Copy-paste this into each directory. **Rule #1: keep every field byte-for-byte identical
across all sites** — same spelling, spacing and punctuation. Consistency is what Google
trusts; inconsistency (e.g. "Govind Nagar" vs "Gobind Nagar", or two phone numbers) actively
hurts local ranking. Work top to bottom — the first two matter most.

## DIRECTORY-BY-DIRECTORY (priority order)

Legend: 🔴 = highest value, do first.

### 1. 🔴 Bing Places for Business
- **URL:** https://www.bingplaces.com
- **Why:** Second-biggest map after Google; also powers Microsoft/Copilot answers.
- **Sign in with:** a Microsoft account (create a free one with contact@verelios.com if needed).
- **Shortcut:** it can **import directly from your Google Business Profile** — choose that
  option to auto-fill everything, then just verify. Fastest listing you'll do.
- **Fields:** canonical block + primary category "Software company" + long description +
  website + hours (24h) + photos (logo, office exterior, team, work screenshots).
- **Verification:** phone or postcard.

### 2. 🔴 Apple Business Connect
- **URL:** https://businessconnect.apple.com
- **Why:** Maps on every iPhone; Siri/Apple Maps search.
- **Sign in with:** your Apple ID.
- **Fields:** canonical block + category (choose "Company" → software/IT) + long description +
  hours + logo & cover image.
- **Verification:** phone/business documents.

### 3. JustDial
- **URL:** https://www.justdial.com/ (scroll to "Free Listing" / jdbusiness.justdial.com)
- **Why:** India's biggest directory; the ones out-ranking you live here.
- **Fields:** canonical block + categories (add all secondary ones — JustDial lets you pick
  several) + medium/long description + services list + photos + WhatsApp number.
- **Verification:** OTP to the phone number.
- **Note:** expect upsell calls for paid plans — the free listing is enough; you can decline.

### 4. Sulekha
- **URL:** https://www.sulekha.com/ (Business → List your business)
- **Fields:** canonical block + category "Software Development / Web Design" + medium
  description + services.
- **Verification:** OTP.

### 5. IndiaMART
- **URL:** https://www.indiamart.com/ (Sell → Start Selling / Free listing)
- **Why:** Huge for B2B; good for ERP/software enquiries.
- **Fields:** canonical block + product/service catalogue (add each service as a "product"
  with the short description) + long company description.
- **Verification:** OTP.

### 6. 🔴 Clutch.co
- **URL:** https://clutch.co/ (Get Listed / "Add your agency")
- **Why:** The #1 agency directory globally; strong for software/dev credibility & backlinks.
- **Fields:** canonical block + long description + services with **percentage focus** (e.g.
  Web Dev 40%, App Dev 25%, Custom Software 20%, AI 15% — adjust to reality) + min project
  size + hourly rate band + portfolio items + team size + founding year.
- **Verification:** email; profile then benefits hugely from client reviews (Clutch calls
  them for a short interview — line up 2–3 happy clients).

### 7. GoodFirms
- **URL:** https://www.goodfirms.co/ (Get Listed)
- **Why:** Sister to Clutch in importance for dev agencies.
- **Fields:** same as Clutch — description, service focus %, project size, hourly rate,
  portfolio, team size, founding year.
- **Verification:** email + optional client reviews.

## THE ONE MISTAKE TO AVOID
Do **not** create a second listing if one already exists (some directories scrape businesses
automatically). Search each site for "Verelios Labs" first — if a listing is already there,
**claim** it rather than adding a new one. Duplicates split your signal and hurt ranking.

Log every listing in the tracker so you can update them all if any detail ever changes.
